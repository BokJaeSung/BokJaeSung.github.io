AS

4 min · AA

1. 개요#

AS(Autonomous System)는 한 회사가 하나의 정책으로 운영하는 라우터와 IP 대역의 묶음이다. 쉽게 말해 “인터넷 위의 회사 하나” 다. KT 의 라우터·회선·IP 대역 전체가 AS 하나이고, 번호는 AS4766 이다. 구글은 AS15169, Cloudflare 는 AS13335 다.

인터넷은 이런 AS 수만 개가 서로 이어진 것이다. AS 안의 길은 그 회사가 알아서 정하고, AS 와 AS 사이에서는 BGP 로 “이 대역은 나에게 오라” 를 주고받는다.

2. AS 가 가진 것#

번호
AS4766. 전 세계에서 겹치지 않게 지역 인터넷 등록 기관(APNIC, 한국은 KISA 를 거쳐)이 나눠 준다
대역
이 AS 가 주인인 IP 대역들. KT 는 약 2,600개 대역을 광고한다 (2026년 10월 조회)
라우터와 회선
회사 건물·국사·데이터센터에 흩어진 라우터와 그 사이 케이블. 전부 이 회사가 관리한다
정책
어느 이웃과 이어질지, 어느 길을 먼저 쓸지, 무엇을 광고할지. 회사가 정한다

3. 집과 AS#

집은 AS 가 아니다. 공유기가 받은 공인 IP 는 통신사 대역의 한 주소이고, 집은 통신사 AS 의 맨 끝에 붙은 손님이다. 바깥에서 보면 우리 집으로 오는 패킷도 “KT AS4766 으로 가는 패킷” 이다.

내 공인 IP 가 어느 AS 에 속하는지는 직접 확인할 수 있다.

# 내 공인 IP
curl -s https://ifconfig.me

# 그 IP 를 광고하는 AS
whois -h whois.cymru.com " -v $(curl -s https://ifconfig.me)"

결과의 첫 칸이 AS 번호, 마지막 칸이 회사 이름이다. 집에서 실행하면 가입한 통신사가, 회사 와이파이에서 실행하면 회사가 쓰는 통신사가 나온다.

4. AS 를 갖는 곳#

AS 가 필요한 건 바깥으로 가는 길을 스스로 골라야 할 때다. 통신사 하나에만 붙어 있으면 고를 길이 없으니 AS 도 필요 없다.

AS 를 갖는 곳
통신사(KT·SKB·LGU+), 클라우드(AWS·구글·Cloudflare), 큰 서비스(네이버·카카오), 대학망, 통신사 여러 곳에 동시에 붙는 기업
갖지 않는 곳
집과 대부분의 회사. 통신사 하나에만 붙어 있어 고를 길이 없으니 통신사 AS 의 일부로 지낸다

5. 안과 밖#

AS 안과 밖은 길을 정하는 방식이 다르다.

  • 안 — 회사가 자기 라우터끼리 쓰는 방식(OSPF, IS-IS 같은 내부 라우팅 프로토콜)으로 길을 정한다. 바깥에서 받은 경로는 iBGP 로 안의 라우터들에게 나눠 준다
  • 밖 — 다른 AS 의 라우터와는 eBGP 로만 이야기한다. 상대 AS 안의 구조는 모르고, 상대가 광고하는 대역과 AS_PATH 만 본다

그래서 BGP 의 경로 단위는 라우터가 아니라 AS 다. AS_PATH 64500 15169 는 “AS64500 을 지나 AS15169 로” 라는 뜻이지, 그 안의 라우터 몇 대를 거치는지는 말하지 않는다.

6. AS 번호#

1 ~ 64495
공개 번호. 인터넷에서 실제로 쓰는 2바이트 번호
64496 ~ 64511
문서·예시용. 이 위키의 AS64500 같은 것
64512 ~ 65534
사설용. 회사 안, 쿠버네티스 클러스터 안. Calico 기본값이 64512
65536 이상
4바이트 번호. 2바이트가 모자라 늘렸다 (최대 약 43억)

처음에는 2바이트(65,535개)였는데 모자라서 4바이트로 늘렸다. 공개 번호는 지역 인터넷 등록 기관(아시아·태평양은 APNIC)이 나눠 주고, 한국 기관은 KISA 를 통해 받는다.

7. 쿠버네티스의 AS#

Calico 는 클러스터 안에서 BGP 를 쓰기 때문에 AS 번호가 필요하다. 기본값은 사설 번호 64512 이고, 모든 노드가 같은 AS 에 속한다. 랙 스위치와 BGP 로 이어질 때는 망 관리자가 정한 번호에 맞춘다.

calicoctl get nodes -o wide                      # ASN 칸에 (64512) — 괄호는 기본값을 물려받았다는 뜻
calicoctl node status                            # 이웃 노드와의 BGP 세션 (Established)

8. 관련 문서#

  • BGP — AS 와 AS 가 대역을 광고하는 방법
  • Subnet — AS 가 가진 대역의 단위
  • DHCP — 집이 통신사 AS 의 주소를 받아 오는 방법
  • CNI — Calico 가 클러스터 안에서 사설 AS 를 쓴다

9. 출처#

AS 의 정의는 RFC 1930 이 내린다.

“An AS is a connected group of one or more IP prefixes run by one or more network operators which has a SINGLE and CLEARLY DEFINED routing policy.”

  • RFC 1930 — Guidelines for creation, selection, and registration of an Autonomous System (AS)
  • RFC 6793 — BGP Support for Four-Octet Autonomous System (AS) Number Space
  • RFC 5398 — AS Number Reservation for Documentation Use
  • RFC 6996 — Autonomous System (AS) Reservation for Private Use
  • RIPEstat — Announced Prefixes — AS 가 광고하는 대역 수 조회
