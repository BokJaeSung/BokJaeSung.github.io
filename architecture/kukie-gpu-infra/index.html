정보

이 레포가 맡는 것

  • GPU 서빙용 쿠버네티스 클러스터 kukie-gpu: 네트워크, 일반 노드, GPU 노드 그룹(g6e, 평소 0대)
  • 클러스터 안 GPU 구성: NVIDIA 장치 플러그인, GPU 지표, vLLM 모델 서버
  • 1단계 실측용 GPU 서버 llm-bench (평소 중지)
  • 배포 역할과 러너는 맡지 않는다 → kukie-infra 가 만든다

색 = 적용 방식

  • 관리자 로컬 관리자가 직접 적용. 매니페스트는 kubectl, llm-bench 는 terraform
  • /apply 댓글 PR 병합 뒤 최종 plan 을 확인하고 댓글로 적용
  • CI 보라는 plan · apply 를 실행하는 쪽(워크플로 · 러너)

권한

  • 이 레포의 역할은 모두 GPU 천장(권한 경계) 안에서만 만들 수 있다
  • GPU 천장은 kukie-dev · 호스팅 클러스터의 리소스를 거부한다 → 클러스터끼리 서로 못 건드린다

아이콘

  • 보라 Terraform 로고 = Terraform root · 파랑 Kubernetes 로고 = 쿠버네티스 매니페스트 · 파랑 CI · 초록 스크립트 · 호박색 폴더 · 회색 파일
